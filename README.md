# AboutTime WearOS

A natural language fuzzy time watch face for Wear OS.

## Supported Devices

- Samsung Galaxy Watch 4
- Samsung Galaxy Watch 5
- Samsung Galaxy Watch 6
- Samsung Galaxy Watch 7


## Features

- Chinese fuzzy time display
- AMOLED black background
- AOD support
- Low power design


## Build

GitHub Actions automatically builds APK.
